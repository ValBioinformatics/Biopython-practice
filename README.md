# Biopython Practice Journal
The vast amount of biological data currently available is a very valuable source of information, but it also presents an endless amount of work to analyze that data; tools such as bioinformatics and data science allow us to carry out that work. Here is a learning journal on Biopython, an excellent tool for genomic data analysis. 

# Python for Bioinformatics 

Practical exercises in Python applied to biological sequence analysis, built while completing my professional internship at the Centro Nacional
de Secuenciación Genómica (CNSG), at University of Antioquia.

# Topics covered
- DNA and RNA sequences manipulation with Biopython
- GC content analysis and sequence statistics
- NCBI GenBank file parsing
- Primer design and Tm calculation
- Batch sequence processing

# Tools
- Python 3.10
- Biopython
- pandas 

Based on "Python para Bioinformática" and the official Biopython Tutorial.
